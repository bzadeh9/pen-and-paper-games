Add Ultimate Tic-Tac-Toe game with standard and strict modes

Implements a new game featuring:
- 3x3 grid of 3x3 tic-tac-toe boards (81 cells total)
- Two game modes: Standard (play anywhere) and Strict (strategic board restrictions)
- Local board win detection and global win conditions
- Responsive design for mobile and desktop
- Game statistics tracking with localStorage
- Comprehensive unit tests for game engine
